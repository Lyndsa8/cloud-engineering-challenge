Cloud Engineering Challenge

Part 4: Research Task
1 What is cloud computing?
Cloud computing is the on-demand delivery of IT resources (like servers, storage, and databases) 
over the internet with pay-as-you-go pricing.

2 What is DevOps?
DevOps is a set of practices that combines software development (Dev) and IT operations (Ops) to
shorten the systems development life cycle and provide continuous high-quality delivery.

3.Difference between Docker and Kubernetes?
Docker is a platform used to bundle applications into containers, while Kubernetes is an
orchestration tool used to manage and scale those containers across a cluster of machines.

4.Why are Linux skills important in cloud engineering?
Linux is the underlying operating system for most cloud infrastructure and container technologies.
Proficiency in the Linux CLI is essential for automation, configuration, and server management.

Part 5: Problem Solving
If a cloud server becomes inaccessible, I would check:
1.Network Connectivity: Use tools like ping or traceroute to see if the server is reachable over
the network.
2.Security Group Rules:Verify that the cloud firewall rules (SSH/HTTP) allow traffic from my current
IP address.
3.Instance Status: Check the cloud provider's console to see if the instance is running or if it
has failed system health checks.
